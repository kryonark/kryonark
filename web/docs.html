How Kryonark
works.

Lock collateral on the chain where it lives, open a tokenized stock position on Robinhood Chain in one signature, and let an AI agent keep it healthy. This page covers the model, the maths, the agent and the tools.

Overview

Tokenized stocks live on Robinhood Chain. Most crypto lives somewhere else: SOL on Solana, BTC on Bitcoin, USDC on Base and Arbitrum. Kryonark lets that crypto back stock positions without moving it.

Any chain in

Collateral from Solana, Bitcoin, Ethereum, Base, Arbitrum, Optimism, Polygon and Robinhood Chain.

Stocks out

Positions in tokenized stocks such as NVDA, AAPL, AMZN and TSLA on Robinhood Chain.

One signature

An intent-based flow locks, messages and opens in one step. No manual bridging.

Guarded every block

An AI agent watches health and tops up before liquidation.

Opening a position

  1. Sign once on the chain that holds your collateral, for example 400 SOL on Solana against an NVDA position.
  2. The vault on the home chain locks the collateral.
  3. A cross-chain message (LayerZero V2) carries the lock proof to Robinhood Chain.
  4. Robinhood Chain opens the stock position, sized so that health starts above the guard line.
  5. The agent starts watching. Close any time: repay on Robinhood Chain, collateral unlocks at home.

Health factor

health = collateral value × 0.8 ÷ position value
HealthStateWhat happens
≥ 1.30SafeNothing; the agent keeps watching
1.00 – 1.30GuardThe agent tops up from your buffer
< 1.00LiquidatableThe position can be liquidated

Example: 412.5 SOL at $147 is $60,638. At a 0.8 threshold that counts as $48,510. Against a $26,650 NVDA position, health is 1.82. If SOL fell 10%, health would drop to 1.64 and still be safe.

The AI agent

The agent reads prices for both sides of every position each block. When a position nears the guard line, it moves USDC from the buffer you allowed into that position, then posts the action to your history.

It signs with a session key that can only add collateral to your own positions. See Security → Agent session key for the full scope.

npm package and CLI

The engine's maths and intent layer is open source as kryonark on npm. No dependencies, Node 18+.

CLI

npx kryonark                                     # example book at live prices
npx kryonark plan "Protect NVDA if SOL drops 10%"  # what the agent would do
npx kryonark prices                              # live SOL, BTC, ETH spot
npx kryonark --json                              # machine-readable

Library

import { spotPrices, exampleBook, health, bookHealth, plan } from "kryonark";

const prices = await spotPrices();
const book = exampleBook(prices);
health(book[0], prices);        // 1.82
bookHealth(book, prices);       // the whole book
plan("Close TSLA", book, prices);

Source: github.com/kryonark/kryonark.

FAQ

Can I use Kryonark today?

The engine is live as a preview on the home page and as npx kryonark. Vault contracts go to Robinhood Chain testnet next; the site doesn't ask for a wallet until then.

Is my collateral bridged?

No. It's locked on its home chain; only a message crosses chains.

What if the agent goes offline?

Your position keeps its collateral and buffer. You can top up or close it yourself at any time.

Where are the official links?

kryonark.xyz, github.com/kryonark and the kryonark npm package.
